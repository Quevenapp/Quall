com assunto `Quall Studio — segurança`.

Prefira uma prova sintética. Não publique detalhes exploráveis em uma issue nem envie senhas,
chaves privadas, PINs reais, identificadores de aparelhos, pares persistidos ou conteúdo pessoal.
Se algum dado sensível for necessário, explique a necessidade antes de enviá-lo.

O endereço é o contato informado; não há promessa de SLA, programa de recompensa,
confidencialidade absoluta ou operação de canal privado verificada neste documento.
Nenhuma habilitação de GitHub Private Vulnerability Reporting é afirmada aqui.

Identifique app, extensão iOS, câmera virtual, plugin OBS ou ferramenta e se o problema envolve
fonte, build local ou pacote distribuído. Use somente sistemas e dados autorizados.

Pares, preferências e textos podem permanecer no aparelho; gravação depende do fluxo escolhido.
Comunicação direta não garante proteção em qualquer rede ou sinalização universal com TLS.
Este snapshot não representa auditoria completa de segurança ou privacidade.
