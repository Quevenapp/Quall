# Quall Studio — insumos da marca oficial para Windows

quall.ico e as três imagens PNG identificadas em ORIGEM.json são os insumos
originais aprovados da marca desta preparação Windows 1.0.0. O ICO é idêntico
a apps/windows/quall.ico usado no executável; os PNGs alimentam a receita MSIX.
Os placeholders geométricos da base pública são materiais próprios separados,
cobertos pela MPL-2.0 conforme seus avisos.

O código do app, núcleo e receita conserva suas licenças. Essa concessão não
concede automaticamente direitos de marca, endosso ou autorização para identificar
builds de terceiros como distribuição oficial. Não transforma estes assets em MPL.

É permitida a reprodução técnica destes arquivos como insumos da receita desta
versão para compilar, testar e relinkar o aplicativo, mantendo este aviso. Não há
autorização para usar a marca em outro produto nem para apresentar uma versão
modificada como publicação oficial de Quall Studio/Quéven. Para distribuição
com outra identidade, usar placeholders neutros ou arte própria. Titulares e
demais direitos da marca permanecem preservados.

Os arquivos foram fornecidos pelo responsável da distribuição oficial,
Veneri & Quellis Ltda. Este aviso não declara cessão de direitos de autores
nem altera licenças ou direitos de componentes terceiros. Não redistribui fontes
tipográficas, imagens de pessoas ou conteúdo de usuários. Conferir os hashes
antes de substituir os insumos. A exceção de marca em LICENSE-SCOPE.md continua.
