# Instrumentos de diagnóstico DV

Código de diagnóstico para captura DV/DVD, análise de MP4, áudio e desentrelaçamento.
A pasta tem um app Android/JNI e instrumentos para mídia sintética; não é uma variante
do Quall Studio distribuída ao usuário.

Use fontes e acessórios autorizados. Identifique formatos, arquitetura e capacidades antes
de interpretar resultados. Códigos de prova não demonstram funcionamento universal de USB/DVD,
nem a disponibilidade de uma biblioteca/codec no pacote final do produto.

Automações privadas de aparelhos e testes dependentes de stubs não acompanham este snapshot.
Não há binários, mídia ou resultados privados para reproduzir uma corrida histórica.
Confira dependências e [escopo de licença](../../LICENSE-SCOPE.md) antes de compilar ou reutilizar.
Veja o [app Android](../../apps/android/README.md) e [limites](../../docs/limites.md).
