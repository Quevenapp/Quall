# Instrumentos de tela estendida — escopo futuro

Ferramentas experimentais para observar sessões, carga e apresentação. Monitor/Tela estendida
e sudoVda estão fora da primeira release nas quatro plataformas. A presença deste código no
fonte não oferece essa capacidade no produto nem um driver para download.

Não instale driver, altere confiança do sistema ou execute scripts em aparelhos para apenas
conferir o snapshot. Revisão de dependências, parâmetros e efeitos é necessária antes de qualquer
ensaio autorizado. Não há mídia, logs ou identificação de aparelhos de corridas anteriores.
